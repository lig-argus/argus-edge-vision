# NPU 작업본과 참고 원본

현행 실행/수정 경로: `work/argus_vision_bus`.
실행 진입은 C++ OnboardMain → CompositionRoot → PerceptionWorker다.
Python 전처리/YOLOX/박스 JPEG/BusProxy/도구는 역할별 하위 패키지에 남겼다.

```text
npu-test/
├── AGENTS.md                    현행 경로 / 다른 AI의 자동 원복 방지
├── work/argus_vision_bus/        cpp/ + python/ + config/ + docs/ + legacy/
├── teammate/argus_vision_bus/    과거 원본 / 실행 기준 아님
└── backups/                     변경 전 백업 / 자동 복원 대상 아님
```

기존 Python 원본은 작업본 `legacy/python/` 아래 `.py.org`로 보존했다.
그 파일을 `.py`로 되돌리거나 옛 `src/argus_vision` 실행 구조를 다시 만들지 않는다.
사용자가 이후 명시적으로 변경하면 그 지시를 우선한다.
모델과 실제 runtime.env/profiles.toml은 전환 시 유지했다.

## 미구현 표시 파일

현행 작업본의 [UNIMPLEMENTED_FILES](work/argus_vision_bus/docs/UNIMPLEMENTED_FILES.md)에
사용자가 승인한 30개 역할/54개 파일의 이름·폴더·흐름도 근거가 있다.
파일은 주석만 있고 빌드/팩토리에 연결되지 않는다. 실제 미구현 기능은 그대로 미구현이다.
