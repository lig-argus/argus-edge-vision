```mermaid
flowchart LR
    SRC[C++ IFrameSource] --> Q[C++ FrameQueue / 2 FIFO]
    Q --> IPC[C++ PythonVisionAdapter]
    IPC --> PRE[Python Preprocessor]
    PRE --> YOLO[Python YOLOXDetector / Hailo]
    YOLO --> BOX[C++ BoxPostprocessor / Observation]
    BOX --> BUS[C++ MessageBus → Python BusProxy]
    PRE --> OVER[Pi Python OverlayEncoder]
    YOLO --> OVER
    OVER -->|박스 포함 JPEG| BUS
    BUS -->|Wi-Fi| PC[PC 구독자]
    BOX -. 미구현 .-> TRACK[ITracker / CameraMotion]
    TRACK -. 미구현 .-> CONTROL[최신 상태 / 독립 제어 / Guard / VehiclePort]
```

현재는 `perception_only`다. 실제 Tracker·CMC·기체 제어 구현이 완료됐다는 뜻이 아니다.
전체 박스만 사용하고 hull ROI는 폐기했다. 인지 큐는 기존 용량 2 FIFO다.
노출 시각과 수신 시각, 예측 결과와 마지막 실제 검출 TTL은 각각 구분한다.

빌드/실행 방법은 [작업본 README](npu-test/work/argus_vision_bus/README.md),
흐름도 이름별 파일은 [FILE_MAP](npu-test/work/argus_vision_bus/docs/FILE_MAP.md),
구현/미구현 구분은 [FLOW_ALIGNMENT](npu-test/work/argus_vision_bus/docs/FLOW_ALIGNMENT.md),
검증 결과는 [VALIDATION](npu-test/work/argus_vision_bus/docs/VALIDATION.md)에 있다.
