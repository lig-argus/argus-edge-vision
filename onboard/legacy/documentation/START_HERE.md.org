# 먼저 읽기

1. Raspberry Pi 5에서 이 폴더로 이동한다.
2. `bash scripts/setup_rpi.sh`를 실행하고 재부팅한다.
3. Hailo-8용 YOLOX HEF를 `models/`에 복사한다.
4. `config/runtime.env`에서 HEF와 라벨 경로를 수정한다.
5. `bash scripts/service_entrypoint.sh check`로 장치를 검사한다.
6. 수동 실행은 `./scripts/run_rpi.sh`이다.
7. 부팅 자동 실행은 `bash scripts/install_autostart.sh`이다.

상세 설명: `docs/INSTALL_AND_RUN_RPI5_HAILO8.md`

주의: 모델 HEF는 이 ZIP에 포함되어 있지 않다. Hailo-8용 HEF와 정확히 일치하는 라벨 파일을 준비해야 한다.
