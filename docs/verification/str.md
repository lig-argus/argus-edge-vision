## 3. 성능 분석

파이프라인 성능 시험에서 프로세스 간 IPC(ZeroMQ)는 FPS에 영향이 없었고, 병목은 카메라 입력·영상 전처리·NPU 추론 구간으로 판단하였다. 측정은 공용 보드의 원본 코드를 수정하지 않고, 복사본으로 기준 측정 후 수정본과 비교하는 방식으로 수행하였다.

| 구간 | 평균 시간 (ms) | 비고 |
|---|---|---|
| 카메라 획득 | 약 33 | 30 FPS 카메라 주기 |
| 전처리 | 약 8 |  |
| NPU 추론 | 약 12 |  |
| 후처리·추적 | 약 3 |  |
| IPC 전달 | 약 1 | FPS 영향 없음 |
| 제어·명령 송신 | 약 5 |  |

개선 방향: 전처리 C++ 이전·최적화, 카메라 획득과 추론의 병렬화.

## 6. 결론

요구사항 31건 중 통과 27건, 부분 통과 2건(FUN-01, FUN-03), 진행 중 2건(FUN-08, ENV-04)이다. 부분 통과 항목은 전차 학습 모델 적용과 탑재용 IR 카메라 수리 후 재시험하고, 진행 중 항목은 실내 호버링 안정화 후 수행하고, 실외 비행(TC-18)은 L3 완료 후 수행한다.
