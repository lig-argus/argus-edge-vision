## 1. 시험 개요

본 절차서는 SRS 요구사항 31건을 시험 케이스 18개(TC-01~TC-18)로 검증한다. 시험은 위험이 낮은 단계부터 수행하며, L1·L2는 통합 시험, L3·L4는 체계 시험에 해당한다. 시험계획(STP)은 간략화하여 본 문서 1~3장(시험 단계·환경·진입/종료 조건)으로 갈음한다.

| 단계 | 내용 | 해당 TC |
|---|---|---|
| L1 HW 연결 | 카메라·NPU·토픽·FC 연결을 드론 없이 시험 | TC-01~05, 08, 10, 17 |
| L2 재생·SITL 통합 | REPLAY / SITL_IMAGE / SITL_POSE로 추적·제어·안전 로직 시험 | TC-06, 07, 09, 11~14 |
| L3 실내 비행 | F450 실내 저속·저고도 비행 | TC-13(재수행), TC-15, TC-16 |
| L4 실외 비행 | F450 실외 저속·저고도 추종 비행 | TC-18 |

## 2. 시험 환경

| 항목 | 구성 |
|---|---|
| 온보드 | Raspberry Pi 5 + Hailo-8(AI HAT+), Ubuntu 24.04, HailoRT |
| 영상 입력 | USB 웹캠(기본), 대형 IR 카메라, 기록 영상(REPLAY). 탑재용 IR은 수리 후 REAL_IR로 추가 수행 |
| 비행 | F450 + KoA FC(PX4, USB 연결), 옵티컬플로우·거리센서, 프로펠러 가드, T8FB 조종기 |
| 시뮬레이션 | PX4 SITL + Gazebo (WSL + Docker, Ubuntu) |
| 표적 | RC 전차 M1A2(약 51×18×20cm), 기만용 차량 모형 |
| 장소 | 강의실 실내(L3, GPS 미사용, 바닥 테이프 무늬), 실외 시험장(L4) |
| 기록 | Recorder 로그, PX4 ulog, 화면 녹화 |

## 3. 진입·종료 조건

- L1 진입: 대상 커밋이 GitHub develop에 병합됨, 보드에 동일 커밋 배포, HEF 파일명 기록.
- L2 진입: L1 케이스 모두 통과.
- L3 진입: L2 안전 케이스(TC-12~14) 통과, 수동 호버링 안정 확인, 고도 제한·프로펠러 가드 장착, 조종자 대기.
- L4 진입: L3 실내 추종(TC-15) 통과, 시험장 비행 허가 확인, 조종자 대기.
- 중단: 기체 이상 거동, 조종자 판단, 배터리 경고 시 즉시 RC 전환 후 착륙.
- 종료: 모든 케이스 수행 또는 미수행 사유 기록, 결과를 STR에 반영.
- 성능 측정 원칙: 공용 보드의 원본 코드는 수정하지 않고 복사본으로 기준 측정 후 비교한다.

## 4. 시험 케이스

| TC | 대상 SRS | 단계 / 프로파일 | 절차 | 판정기준 |
|---|---|---|---|---|
| TC-01 입력원 교체 | FUN-01 | L1 / 웹캠 → REPLAY → IR | 설정 파일의 입력원만 바꿔 재시작, 각 입력에서 60초 실행 | 코드 수정 없이 세 입력 모두 탐지 결과 출력 |
| TC-02 프레임 폐기 | FUN-02 | L1 / REPLAY | 추론보다 빠른 속도로 프레임 공급, 대기 프레임 수·프레임 연령 기록 | 대기 프레임 수 상한 유지, 처리 프레임 연령 증가 없음 |
| TC-03 NPU 탐지 | FUN-03, IF-02 | L1 / 웹캠 | hailortcli로 장치·PCIe Gen3 확인 후 HEF 로드, 전차 촬영 | 박스·신뢰도·t_frame이 출력되고 통제기에 표시 |
| TC-04 추론 FPS | PRF-01 | L1 / REPLAY | 동일 영상 3회 재생, 구간별(획득·전처리·추론·후처리) 시간 기록 | 평균 FPS ≥ 20 |
| TC-05 정확도·오탐 | PRF-04 | L1 / 테스트 데이터셋 + 실물 배치 | 테스트셋 mAP 산출, 전차와 차량 모형을 함께 두고 거리·각도 변경 촬영 | mAP@0.5 ≥ 0.80, 차량 오탐률 ≤ 5% |
| TC-06 ID 유지 | FUN-04, FUN-07, PRF-03 | L2 / REPLAY, SITL_IMAGE | 대상 지정 후 교차·가림·재등장 구간 재생 | 유지율 ≥ 90%, 겹침 시 ID 전환 0회 |
| TC-07 카메라 모션 보상 | FUN-05 | L2 / REPLAY(IR+FC 로그) | 같은 로그를 CMC 켜고/끄고 비교 | CMC 적용 시 ID 전환·유실 감소 |
| TC-08 토픽 발행 | FUN-06, FUN-10, IF-03 | L1 | 구독 도구로 `tracking/tracks`, `follow/status` 두 토픽 수신, 필드 점검 | `process_interfaces.md` 5.1.1, 5.1.2 의 필드가 모두 존재, `seq` 증가 |
| TC-09 E2E 지연 | PRF-02, FUN-12 | L2 / SITL_IMAGE | t_frame→t_cmd 차이를 5분간 기록 | p95 ≤ 150 ms, 로그 누락 없음 |
| TC-10 FC 연동 | IF-01, SAF-05 | L1 / 실기체(프로펠러 제거) | USB 연결, mavlink-router 경유로 텔레메트리 수신·명령 송신, FC 로 명령을 보내는 프로세스 수 확인 | 자세·배터리 수신, 명령 ACK, 송신자 mavlink_gateway 1개 |
| TC-11 통제기 명령 | FUN-11, IF-04 | L2 / SITL | TRACK_START·TRACK_STOP 송신, 같은 명령 번호(param7)로 재전송 | 모든 명령에 COMMAND_ACK 회신, 재전송은 한 번만 처리 |
| TC-12 대상 소실 | SAF-01, FUN-09 | L2 / SITL_POSE | 추종 중 대상 제거 후 다른 객체 등장 | 예측 유지 기한 만료 후 표적 상태 LOST, Hold 전환, 다른 ID 미추종 |
| TC-13 RC 오버라이드 | SAF-02 | L2 SITL → L3 실내 | 추종 중 T8FB 스틱 입력 | SW 명령 즉시 중단, 조종자 제어 복귀 |
| TC-14 stale·한도 | SAF-03, SAF-04 | L2 / SITL | 추적기 프로세스 강제 종료, 한도 초과 명령 주입 | stale 트랙 명령 미송신, 한도 초과 명령 제한·거부 |
| TC-15 실내 추종 | FUN-08, ENV-04 | L3 / 실내 실기체 | 호버링 안정 확인 후 저속으로 이동하는 전차 추종 | 영상 중심 오차 80 px 이내 유지(640×480 기준), 수평 드리프트 0.5 m 이내 |
| TC-16 전력·중량 | PRF-05, ENV-02, ENV-03 | L1, L3 | 추론 중 보드 전류·전압 측정, 탑재물 계측 | 소비전력 ≤ 12 W, 중량 ≤ 500 g |
| TC-17 환경 점검 | ENV-01, ENV-05 | L1 | OS·HailoRT 설치 상태, 언어 구성, 저장소 브랜치 점검 | 요구 환경과 일치 |
| TC-18 실외 추종 | FUN-08, SAF-02 | L4 / 실외 실기체 | 위치 유지 확인 후 저속으로 이동하는 전차 추종, 추종 중 RC 스틱 입력 | 영상 중심 오차 80 px 이내 유지(640×480 기준), RC 입력 시 SW 명령 즉시 중단 |
